# Simple System Info

A lightweight hardware and system information utility built with Python.

## Prerequisites

* **Python**: 3.8 or higher.
* **Tkinter**: Included by default in most standard Python installations.
*(On Linux, you may need to install `python3-tk` via your system package manager).*

## Installation

1. Clone or download this repository.
2. Install the required external dependency (`psutil`):

```bash
pip install -r requirements.txt

```

## Usage

Run the main script using Python:

```bash
python SimpleSystemInfo.py

```

## Dependencies

* `psutil`: Used for hardware and system resource monitoring.
